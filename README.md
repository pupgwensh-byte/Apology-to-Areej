# موقع أريچ — فراولة 🍓

نسخة جاهزة للرفع على **GitHub Pages**، والأغنية موجودة داخل المشروع بالفعل.

## رفع الموقع على GitHub
1. أنشئ Repository جديد واجعله **Public**.
2. ارفع محتويات هذا المجلد في جذر الـ Repository، بحيث يظهر `index.html` مباشرة وليس داخل مجلد إضافي.
3. افتح **Settings → Pages**.
4. تحت **Build and deployment** اختر **Deploy from a branch**.
5. اختر Branch: `main` وFolder: `/ (root)` ثم اضغط **Save**.
6. بعد النشر سيظهر رابط الموقع داخل صفحة Pages.

## الملفات المهمة
- `index.html`: الموقع كاملًا.
- `assets/ana-baatereflek.mp3`: أغنية «أنا بعترفلك».
- `assets/favicon.svg`: أيقونة الموقع.
- `assets/preview.png`: صورة المعاينة عند مشاركة الرابط.

> لا تحذف مجلد `assets` أو تغيّر أسماء الملفات إلا إذا عدّلت المسارات داخل `index.html`.
