# موقع أريچ — فراولة 🍓

نسخة جاهزة لـ GitHub Pages.

## مهم عند الرفع
ارفع **كل الملفات الموجودة داخل هذا المجلد** مباشرة إلى المستودع، وبالأخص:
- `index.html`
- `ana-baatereflek.mp3`
- مجلد `assets`
- `.nojekyll`

يجب أن يكون ملف الأغنية `ana-baatereflek.mp3` بجوار `index.html` في الصفحة الرئيسية للمستودع، وليس داخل ZIP.

## تشغيل الأغنية
تبدأ الأغنية عند الضغط على زر **افتحي الرسالة**. لو المتصفح منع التشغيل التلقائي، يظهر تنبيه داخل الموقع ويكفي الضغط على زر ▶ مرة واحدة.
